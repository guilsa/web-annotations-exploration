Marginalia

The web is a shared margin.

Reading becomes more useful when the thought beside a sentence can travel with it.

A short note on durable ideas · 4 min read

We remember the web in fragments: a sentence worth returning to, a question for a colleague, a connection that only becomes obvious later.

A useful annotation should be easy to make, simple to keep, and possible to share without asking permission.

The best tools leave the page readable while keeping the conversation close at hand.
