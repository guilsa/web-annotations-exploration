# Textmarker A — Linkshare

A simple Firefox extension: highlight text on any page, attach comments, and
**share them by copying a link**. No server, no account, no config — the URL
fragment is the database.

## How sharing works

1. Select text → the floating pill appears → **💬 Comment** (or `Alt+M`).
2. Write a note (or leave it empty for a plain highlight) → Save.
3. Comments are saved per-URL in `browser.storage.local` and restored when you
   revisit the page (fuzzy text matching: exact offset → whitespace-insensitive
   offset → context-scored window search).
4. **Copy share link** (`Alt+L`, toolbar button, or the panel) copies the page
   URL with all comments base64-encoded into the fragment: `…#section&tmc=<data>`.
5. The recipient opens the link (with the extension installed): a banner shows
   the shared comments rendered in purple; they can **Import all** (or
   import single ones via the hover card) to keep them locally and keep
   commenting. Re-sharing sends an updated link.

Everything is offline. The only "distribution" is the link itself — paste it
anywhere (chat, email, issue tracker).

## Load in Firefox

1. `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on…**
2. Pick this folder's `manifest.json`.
3. Open any http(s) page, select some text.

## Design notes

- **Zero config, good defaults**: one highlight color, one comment per
  selection, per-URL persistence, fuzzy restore with automatic retry (the page
  may load content asynchronously), `Esc` closes everything.
- **Robustness**: all UI (pill, card, editor, banner, panel, toast) lives in
  shadow roots so page CSS can't break it; highlight spans are plain `<span>`s
  with `!important` backgrounds; our own injected UI is excluded from text
  indexing via `data-tma-skip`.
- **Restore model**: each mark stores `quote` + `pre`/`post` context + the
  character `offset` in the page's concatenated text. On revisit the text is
  re-indexed and the mark is re-located by tiered matching
  (context+window → context → long-quote window). Marks that can't be found
  are retried for a few seconds (dynamic pages) and then reported in the panel.
- **Limitations** (kept simple on purpose): no iframes, no per-comment author
  profiles, shared layer is read-only until imported, one entry per URL.

## Files

- `manifest.json` — MV3, content script + tiny background (toolbar/commands relay)
- `background.js` — relays toolbar clicks and `Alt+M` / `Alt+L` commands
- `content.js` — everything else (pure helpers are unit-tested, see `tests/`)
- `icons/` — generated by `tools/make-icons.js`
